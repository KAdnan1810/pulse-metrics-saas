# ⚡ PulseMetrics – Multi-Tenant B2B SaaS Platform

PulseMetrics is a production-ready usage monitoring and rate-limiting SaaS platform built with Spring Boot 3, Redis, PostgreSQL, and React.

## 🚀 Tech Stack
- **Backend:** Java 21, Spring Boot 3, Spring Security 6 (JWT + RBAC), Spring Data JPA
- **Database & Cache:** PostgreSQL, Redis (Atomic Quota Limiting)
- **Frontend:** React (Vite), Tailwind CSS, Lucide Icons, Axios
- **DevOps:** Docker, Docker Compose, GitHub Actions CI/CD
